# 課程（這門課與這家店的東西都在這裡）

repo 根目錄只放 Claude 的「到職須知與工具」（`CLAUDE.md`、`.claude/`、`.mcp.json`）；換一門課就會換掉的東西，全在這個資料夾。

**給你（人）看、照著做的：**

| 資料夾 | 是什麼 | 什麼時候用 |
|---|---|---|
| `講義/` | 講義一（Claude 會講到的詞）、講義二（每個實作段你對 Claude 說什麼、應該看到什麼） | 整堂課；講師會說現在看哪一段 |
| `手工貼/` | 第一天上午：你自己貼進 Cloudflare 的小程式和步驟 | 環境架設，裝完 Arcrun RAG 之後 |
| `小案子/` | 第一天上午：雲端聊天介面的說明，和要整段貼給 Claude 的那一句 | 環境架設之後 |

**Claude 會讀、會改的（你不用打開）：** `company-data/`（店的規則，會上傳到 Arcrun RAG）、`data/`（舊系統匯出的資料）、`orders/`（儀表板與規格）、`tests/`（驗收單）、`scenario/`（一天的劇本）、`存檔點/`、`wrangler.toml` 與 Claude 蓋出來的 `src/`、`logs/`（紅燈記錄）。
