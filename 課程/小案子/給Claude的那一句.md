# 給 Claude 的那一句（整段貼給 Claude）

> 幫我做一個雲端聊天介面，建在我的 Cloudflare 上，叫 `class-chat`：
> 1. 打開網址是一頁手機看得清楚的聊天頁：上方寫「你現在連到的是 Cloudflare 在＿＿的機房」（城市和機房代碼，沿用我手工貼的那段 `課程/手工貼/貼上就跑.js`），下面是對話框和輸入框。
> 2. 我打一句話，後面由 Workers AI 的小模型用繁體中文簡短回答，要記得前幾輪聊過什麼。
> 3. 程式和驗收題都放在 `課程/class-chat/`（驗收題在 `課程/class-chat/tests/`；它是自己的 Worker 專案，`wrangler` 在那個資料夾裡跑）。動手前先寫驗收題，先讓我看，我說「對」你再蓋。
> 4. 蓋好跑驗收題，全綠才部署；部署後給我網址，我用手機打開。
>
> 步驟之間用一句白話跟我說你在做什麼。這個案子跟烘焙坊無關，Arcrun 裡沒有相關的規則是正常的，查完說一聲就好。

---

## 驗收題要有什麼（講師對照用；Claude 應該自己想到，沒想到就提醒）

| 類型 | 題目 | 應該 |
|---|---|---|
| 答得對 | 送「你好，用一句話介紹你自己」 | 200，回一句中文 |
| 答得對 | 帶著上一輪對話再問「我剛剛問了你什麼？」 | 回得出上一輪的內容（有記得） |
| 陷阱 | 送空白訊息 | 被拒絕（400），不叫小模型 |
| 陷阱 | 送一千個字 | 被拒絕（400），不把額度燒掉 |
| 陷阱 | 小模型那端出錯（測試時換成會丟錯的假模型） | 回一句白話請稍後再試，不是 500 和一長串錯誤 |
| 陷阱 | 網頁顯示對話 | 用文字顯示，不用 innerHTML——對話裡出現 `<script>` 也不會執行 |

## 學員看到的流程

| 順序 | Claude 做什麼 | 你應該看到 |
|---|---|---|
| 1 | 說明打算怎麼蓋，列出驗收題 | 一張驗收題清單，問你「這樣對嗎」，回「對」 |
| 2 | 寫 Worker、加 Workers AI | Claude 問「要建這個 Worker 嗎」，回要 |
| 3 | 跑驗收題 | 一張對照表；**第一次可能有紅燈，這是正常的**，看 Claude 怎麼修 |
| 4 | 部署 | 給你網址 |
| 5 | 你用手機打開 | 看到機房城市；打一句話，幾秒內小模型回你，接著問「我剛剛說了什麼」它答得出來 |

> 沒有資料庫、沒有金鑰、沒有任何設定檔要你填——這就是和傳統 server 最大的差別。
